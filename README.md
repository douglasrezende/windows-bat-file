Explicações:

    taskkill /IM chrome.exe /F: Fecha todos os processos do Google Chrome.
    taskkill /IM msedge.exe /F: Fecha todos os processos do Microsoft Edge.
    timeout /t 600: Espera 600 segundos (10 minutos).
    start chrome.exe "https://www.exemplo.com": Abre o Google Chrome com o link especificado. Você pode alterar para o navegador de sua preferência.

Como usar:

    Abra o Bloco de Notas.
    Cole o código acima.
    Salve o arquivo como abrir_browser.bat (certifique-se de selecionar "Todos os Arquivos" no campo "Tipo").
    Execute o arquivo clicando duas vezes nele.
